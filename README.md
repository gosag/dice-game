# 🎲 Dice Game

A simple **React dice game** built with React and TypeScript. Roll the dice, hold numbers, and try to get all dice with the same value!

## 🚀 Features
- Roll dice
- Hold dice to keep their value
- Win message when all dice match
- Fun and interactive UI

## 🛠️ Tech Used
- React
- TypeScript
- CSS
